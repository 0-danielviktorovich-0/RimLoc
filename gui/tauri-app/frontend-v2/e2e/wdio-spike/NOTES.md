# WDIO spike — заметки об изоляции окружения

## E2E virgin-профиль: user languages НЕ изолируются `RIMLOC_DATA_DIR` (F2, TEST-INFRA)

`RIMLOC_DATA_DIR` изолирует каталог данных приложения (проекты, конфиги), но
**каталог пользовательских языков живёт в WebKit localStorage** — та же память,
где `rimloc.locale`, `rimloc.target.<project_id>` и layout-панели. `RIMLOC_DATA_DIR`
эту память не изолирует: virgin-профиль E2E видит пользовательские языки (и
персистентные выборы целевой локали) от прошлых прогонов на той же машине.

Последствие: тесты, ожидающие «чистый» каталог языков (например
`lm-acceptance`), могут поймать язык, добавленный предыдущим прогоном.

Чистый каталог для прогона — чистить WKWebView storage между сессиями
(webkitmock/`simctl`-путь проекта либо удалить WKWebView data store приложения
перед запуском). Продукт намеренно НЕ меняется: per-app persistence —
сознательное решение, а не дефект.
