# Предпросмотр в GUI и быстрый редактор

Панель Preview в RimLoc позволяет сравнить английский текст (EN) и целевой язык, а также быстро править отсутствующие/устаревшие строки.

Возможности:

- Фильтр ключей по подстроке, режимы «только Missing», «только проблема с плейсхолдерами», «только проблема со списком (li)».
- Клик по ключу показывает EN‑текст и позволяет отредактировать Target; кнопка Apply сохраняет изменения.
- После Apply сохранение происходит в `Languages/<target>/Keyed/_Edited.xml` (создаётся при отсутствии) и предпросмотр обновляется без повтора скана.
- Под редактором отображаются предупреждения: несоответствие плейсхолдеров EN↔Target, различие числа элементов списков (эвристика по переносам строк).

Примечания:

- Детектор плейсхолдеров соответствует CLI (форматы `%s`, `{NAME}` и т. п.).
- Для сборки полноценного мода используйте панель Build (из PO или из существующего дерева).
