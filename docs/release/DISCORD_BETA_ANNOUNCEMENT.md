🚀 **RimLoc — Open Beta**

Переводите моды RimWorld с ИИ или вручную — быстро, безопасно и красиво.

**Что умеет RimLoc:**
🌍 Открывает любой мод RimWorld (1.0–1.6) и показывает все переводимые строки
🤖 ИИ-перевод: локально через Ollama (бесплатно, приватно) или с вашим облачным ключом
✍️ Ручной перевод: удобный редактор с черновиками, которые не теряются
✅ Валидация: плейсхолдеры, дубликаты, переполнения — всё проверяется
📦 Экспорт: готовый мод-перевод для RimWorld, исходный мод не меняется

**Для опытных переводчиков:**
- PO/XLIFF обмен с CAT-инструментами
- Глоссарий и память переводов
- Сравнение версий мода
- Русский и английский интерфейс
- Тёмная тема

**Для ИИ-энтузиастов:**
- Внешний MCP-сервер: подключите Claude/Codex/любого агента к RimLoc
- Агент может переводить моды, пока вы работаете в GUI — изменения видны сразу
- Черновики защищены от конфликтов

**Платформы:**
- macOS (Apple Silicon): протестирована ✅
- Windows / Linux: сборки готовы, ждём первых тестировщиков
