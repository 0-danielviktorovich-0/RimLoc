### Баги Language Manager

1. **БАГ (подтверждён): принимается битый locale-код.** Ввод «1плохо код!» → язык добавлен в список и localStorage (`106/108-BUG-lm-broken-id-accepted.png`). `manager.ts:34-38` проверяет только пустоту и дубликаты — `isValidLocaleId` (он есть в Svelte-реестре, `frontend-v2/src/lib/languages/registry.ts:246`) в React-лейне не вызывается вовсе.
2. **БАГ: пользовательский язык не связан с target** — не появляется в переключателе воркспейса (`App.tsx:8`, `App.tsx:230`). Создать язык можно, выбрать его целью нельзя — функция мандата не собрана.
3. **БАГ (незначительный): сообщение об ошибке не гаснет после успешного действия.** После отклонённого дубликата успешное добавление оставляет старую ошибку висеть (`LanguageManager.tsx:60-62` — в успешной ветке `error` не очищается) (`107-lm-stale-error.png`).
4. **UX: ошибки по-английски в русском UI** — «localeId conflicts with builtin», «localeId already exists» рендерятся как есть (`manager.ts:36-38`), локализации нет.
5. **БАГ (смежный экран воркспейса): захардкоженная подпись «ПАПКА ПЕРЕВОДА: Languages/Russian»** (`Workspace.tsx:95`) — видна даже при активном uk-target (виден на `111-BUG-lm-commit-uk-shows-ru.png`).

### Мульти-таргет: найден баг перерисовки (без потери данных)

`project.ts:231` — `commit()` после акка переподчитывает снапшот и **всегда перерисовывает список с/locale `'ru'`** (`entries: mapSnapshot(fresh, 'ru')`), игнорируя активную цель:

- Прогон 1 поймал фазу живьём: после коммита в uk при активном `uk` в списке стоял текст ru (`select=uk showsRuText=true showsUkText=false`, скриншот `111-BUG-lm-commit-uk-shows-ru.png`).
- Прогоны 2–3 (временная шкала 8 с × 500 мс) фазу не поймали: IPC в фоновой карте откладывается на секунды (сам `App.tsx:98-101` документирует класс задержек), поэтому баг фазозависим. Данные не теряются: uk-правка подтверждённо сохраняется и видна после ручного переключения локали. Корректный фикс — `mapSnapshot(fresh, state.targetLocale)`.
