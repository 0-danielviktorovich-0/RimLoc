# MULTILINGUAL ARCHITECTURE — RimLoc

Дата: 2026-09-23 · Итерация 2 · Аудит скрытых EN/RU-допущений (§1) и целевая модель.

## Три независимых понятия

| Понятие | Где живёт | Значения по умолчанию |
|---|---|---|
| **UI locale** | FTL-каталоги CLI (`i18n/en|ru`), `--ui-lang`, в GUI — i18n-каталоги Svelte | ru (предпочтение владельца), en поддержан |
| **Source language** | `--source-lang`/`--source-lang-dir`, конфиг проекта, `TranslateRequest.source_lang` | English (доменное правило RimWorld, см. ниже) |
| **Target language** | `--lang`/`--target-lang`, `TranslateRequest.target_lang` | Russian (пользовательский дефолт, переопределяется) |

Ни одно из них не ограничивает остальные: русский UI умеет переводить ja→en, en→uk и т.д.

## Доменное правило RimWorld (не EN-допущение)

Текст XML-дефов **по конвенции игры** — канонический источник (игра грузит Defs как английскую базу, переводы живут в `Languages/<любой>/`). Поэтому `DEFAULT_SOURCE_LANG_DIR="English"` в сервисах — это фиксация игровой конвенции «Defs = source», а не англоцентризм: для дефолтного пайплайна «извлечь источник» означало «Defs + Languages/English». Явные флаги/пути позволяют выбрать любой язык и любую пару.

## Языковые capabilities — подтверждено официальными паками Ludeon

Эмпирика из официальных репо (детали и доказательства: `OFFICIAL_LANG_PACKS.md`; фикстуры: `testlab/fixtures-official/`):

| Язык | WordInfo | LanguageWorker | Уникальные механизмы |
|---|---|---|---|
| ru | ✓ (Case/Plural/Gender/**Imperfect**/SkillDef_subject) | LanguageWorker_Russian (исходник в репо) | макросы `{X_numCase ? …}`, `{PAWN_gender ? …}`; CI из 6 python-валидаторов |
| de | ✓ (decline.txt: 8 колонок, CSV-заголовок) | встроен в игру | **`{replace:}`-макрос** (вложенный в `{lookup:}`), compound.txt, автогенерация WordInfo через GitHub Actions |
| uk | ✓ (7 падежей с вокативом, rules.txt 12 колонок) | **без воркер-класса** | `{lookup:}` активнее всех; CrowdIn |
| ja / zh | ✗ нет | нет | **легитимное переупорядочивание плейсхолдеров** (`{0},{4},{2},{3},{5}`) |

Выводы для RimLoc:
1. Валидатор плейсхолдеров сравнивает **множества токенов, не позиции** — ja/zh легитимно переставляют аргументы (зафиксировано тестами `reordered_placeholders_are_legitimate_for_cjk`).
2. `{replace:}`/`{lookup:}` ортогональны воркер-классу (3 из 5 языков) — валидатор считает внутренние плейсхолдеры, обёртка не токен (тест `german_replace_macro_inner_placeholders_counted`).
3. WordInfo-генерация — capability только для ru/uk/de-семейства; «не каждый язык — Case/Plural/Gender» подтверждено (ja/zh их не имеют вовсе).
4. Формат файлов нестабилен даже внутри официальных репо (BOM ±, CRLF/LF вперемешку) — парсер обязан быть толерантным.
