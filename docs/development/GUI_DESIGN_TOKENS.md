# GUI Design Tokens — RimLoc: четыре направления

**Статус**: дизайн-фаза, на выбор Даниэля · **Дата**: 2026-09-23
**Связан с**: `GUI_DESIGN_SPEC.md` §1.1–1.4 (тема, палитра-кандидат, типографика) · `GUI_MOTION_SYSTEM.md` (длительности)
**База**: dark primary (тёмная — дефолт, light и system полноправны). Все четыре направления спроектированы в обеих темах интенционально, не инверсией.

## 1. Слои и нейминг

| Слой | Префикс | Содержимое | Кто использует |
|---|---|---|---|
| Primitive | `--p-*` | сырые шкалы (`--p-slate-700`, `--p-copper-600`) | только semantic-слой |
| Semantic | `--color-*`, `--space-*`, `--radius-*`, `--shadow-*`, `--dur-*` | роли: `--color-accent`, `--color-status-error` | все компоненты |
| Component | `--btn-*`, `--chip-*`, `--row-*`, `--input-*` | связки ролей под контрол | контролы |

Объявление: `:root` (light) + `[data-theme="dark"]`; сырой hex в компонентах запрещён (спека §1.2). Смена направления = замена набора semantic-значений, компоненты не трогаются.

## 2. Глобальные правила (для всех направлений)

- **AA-пороги**: пары fg/bg текста ≥ 4.5:1; крупный текст (≥18px), границы несущих элементов (инпуты, focus), иконки-носители ≥ 3:1 (WCAG 1.4.3/1.4.11). Обычные 1px-разделители — декоративные, порог 3:1 на них не распространяется. Контрасты ниже посчитаны по формуле WCAG на родительской поверхности, округлены; при имплементации прогнать contrast-скриптом, падение ниже порога = регресс.
- **Цвет не единственный носитель** (WCAG 1.4.1): статус = точка-цвет + глиф формы (○ untranslated, ✓ translated, → todo, ↻ sourceChanged, ◐ pending_review) + текстовая метка в чипе + число. Provenance — текстовый бейдж `H`/`TM`/`LLM` + tooltip. Цветовые коды origin (human=success-hue, TM=info-hue, LLM=cyan-hue) унифицированы во всех направлениях.
- **Маппинг статусов спеки**: translated→`success`, todo→`info`, orphan→`fg-muted`. v1 читает перечень статусов из сервиса — новые статусы подхватываются без ломки (§6.1 спеки).
- **Инварианты направлений** (варьируется только «кожа», не геометрия): высота строки таблицы 40px, spacing base 4px, виртуализация, двухшрифтовый бандл OFL + системный CJK-фолбэк, радиусы не больше `--radius-lg`.

## 7. Component-слой (общий каркас, дельты направлений)

Токены: `--btn-{bg,fg,radius,hover}` · `--chip-{bg,fg,border}` · `--row-{h:40px,fg,bg-hover}` · `--cell-focus` · `--input-{border,focus}` · `--panel-{bg,radius,shadow}`. Дельты: A — всё на границах, shadow нет; B — floating-слои с двухслойной тенью, кнопка-градиент + solid-фолбэк; C — inset-подсветка, инверсный fg кнопки в dark, радиусы −2 ступени; D — кнопка-чернила, радиусы 2px, колонки различаются шрифтом.

## 8. Типографика, шрифты, лицензии

```css
--font-ui:  "IBM Plex Sans", system-ui, "Hiragino Kaku Gothic ProN", "Yu Gothic UI", "Noto Sans CJK JP", "Microsoft YaHei", sans-serif;
--font-mono:"JetBrains Mono", ui-monospace, monospace;
--font-serif:"IBM Plex Serif", Georgia, serif; /* только направление D, SOURCE-колонка */
```

- **Бандл (woff2, subsets latin+cyrillic, офлайн)**: IBM Plex Sans, JetBrains Mono, + Plex Serif для D. Все три — SIL OFL 1.1: бандл легален, копирайт-уведомления в About. Цена ~сотни КБ — принято в §6.5 спеки.
- **CJK системным фолбэком**: бандлить Noto Sans JP/CJK (2–4 МБ × 4 начертания) для v1 рано; решение — открытый вопрос, триггер: жалобы на «смешение гарнитур» в ja/zh контенте.
- Кириллица у Plex Sans/Mono/Serif полная; верифицировать глифы Ґґ Єє Її (укр.) на скриншотных тестах.

## 9. Имплементация

1. Один файл `tokens/<direction>.css` на направление (semantic-слой), общий `tokens/primitives.css`; переключение направления — data-атрибут рядом с `data-theme`.
2. Контраст-аудит — скрипт (все пары из этого документа как фикс-таблица), гонять в CI на оба режима.
3. Выбор направления — решение Даниэля; до выбора компоненты пишутся только на semantic-слой, чтобы смена была бесплатной.
