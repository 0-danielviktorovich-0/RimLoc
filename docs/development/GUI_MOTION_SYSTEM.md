# GUI Motion System — RimLoc

**Статус**: дизайн-фаза, утверждения не реализованы · **Дата**: 2026-09-23
**Связан с**: `GUI_DESIGN_SPEC.md` §1.4 (движение), §2.4 (Workspace) · `GUI_DESIGN_TOKENS.md` (цвета состояний)
**Профиль продукта**: density 8/10, motion 2/10 — движение обслуживает смену состояния, а не украшает.

## 1. Принципы

1. **Движение = обратная связь**, а не аттракцион: каждая анимация отвечает на действие пользователя или на смену состояния сервиса, читается и без неё.
2. **Только compositor-свойства**: анимируются `transform` и `opacity` (и `color`/`background-color` для точечных свопов состояния ≤140ms). Layout-свойства (`width`, `height`, `top`) не анимируются.
3. **Прерываемость важнее завершённости**: переходы — CSS, не JS; повторное действие (hover, клик, ввод) мгновенно перехватывает текущий переход.
4. **Без overshoot**: только decelerate/accelerate кривые; spring и эластика запрещены (Swiss-дисциплина).
5. **Одно крупное движение на кадр**: EMPHASIS-переходы не накладываются друг на друга.

## 2. Ярусы длительности и кривые

| Ярус | Диапазон | Дефолт | Кривая (cubic-bezier) | Характер |
|---|---|---|---|---|
| FAST | 100–140ms | 120ms | `(0.2, 0, 0.4, 1)` — ease-out-quad | подтверждение уже совершённого действия: hover, фокус, чипы, бейджи |
| STANDARD | 160–220ms | 200ms | `(0.2, 0, 0, 1)` — decelerate | смена структуры видимой области: панели, дропдауны, редактор |
| EMPHASIS | 240–320ms | 260ms | `(0.32, 0.72, 0, 1)` — emphasized decelerate | «крупное» движение кадра: модалка, маршрут, toast |

- **Выход (exit) короче входа**: `cubic-bezier(0.4, 0, 1, 1)` (accelerate), 60% от входной длительности. Исчезновение не должно задерживать внимание.
- **Loop-константы** (единственные разрешённые циклы): skeleton shimmer 1400ms `linear`; indeterminate-прогресс 1600ms `cubic-bezier(0.45, 0.05, 0.55, 0.95)`.
- **Stagger-политика**: допустим только в Home-карточках и шагах мастера — ≤ 8 элементов × 20ms задержки, FAST-длительность. **В Workspace stagger запрещён полностью.**

## 3. Геометрия движения

- Микросмещения (hover/focus/бейдж): translate ≤ 4px, scale не применяется к тексту вообще.
- Панели и контейнеры: translate ≤ 16px + fade; сторона смещения = сторона, откуда пришёл контент.
- Маршруты: направленный translate ±8px (вперёд — слева направо, назад — обратно), fade верхнего уровня.
- Модалка: scale 0.98 → 1.00 + fade; оверлей — отдельный fade FAST. Всё, что больше 0.98, выглядит дёшево; меньше — незаметно.

## 4. Каталог целей

| Цель | Ярус | Свойства | Намерение / ограничения |
|---|---|---|---|
| View transition (Home↔Onboarding↔Workspace) | EMPHASIS 260ms / exit 160ms | opacity + translateX ±8px на chrome-слое | читается как «вперёд/назад»; данные таблицы не анимируются, новый экран готов до старта перехода |
| Sidebar (дерево мод-структуры) | STANDARD 180ms | transform контента + fade вторичного уровня | коллапс сохраняет ориентацию в дереве; ширина контейнера меняется через grid, не через анимацию width |
| Context panel (панель записи) | STANDARD 200ms / exit 120ms | opacity + translateX 16px | связь панели с выбранной строкой; контент меняется fade-кроссфейдом 120ms без сдвига каркаса |
| Modal (диалоги, конфликт sourceChanged) | EMPHASIS 260ms / exit 160ms | scale 0.98→1 + opacity; оверлей FAST 120ms | фокус-захват виден сразу; закрытие по Esc не ждёт анимации семантически |
| Dropdown (меню, локали, вторичные действия) | FAST 140ms / exit 100ms | opacity + translateY(-4px) | мгновенная доступность пунктов; позиционирование без анимации |
| Filter chip (статусы с счётчиками) | FAST 120ms | background-color, border-color, pressed-состояние | таблица после клика обновляется без анимации строк; счётчик меняется свопом текста, не «прокруткой» |
| Inline edit (ячейка TARGET) | STANDARD 180ms | inset box-shadow (фокус-контур) + fade подложки | вход в правку не сдвигает соседние строки; caret и текст появляются мгновенно; высота строки 40px инвариантна |
| Validation feedback (смена статуса записи) | FAST 120ms | color + иконка-глиф свопом | результат виден без анимации (цвет не единственный носитель); сводка проблем — блок fade STANDARD 200ms один раз |
| sourceChanged (бейдж на строке) | FAST 120ms | opacity бейджа | привлекает внимание к записи без изменения высоты строки и без пульсации |
| Progress (фазы сборки) | 200ms на шаг ширины | transform: scaleX полосы | indeterminate — loop 1600ms; проценты и фазы — текстом, без анимации; завершение — один fade 120ms |
| Toast (уведомления) | EMPHASIS 260ms / exit 180ms | translateY(8px) + opacity | периферийное событие; исчезает само; не перекрывает таблицу дольше 4s для инфо-класса |
| Skeleton (загрузка) | loop 1400ms `linear` | opacity shimmer полосы 0.45↔0.65 | структура оккупирует место заранее (8 строк-заглушек), чтобы контент не «прыгал»; отмена операции доступна всегда |

## 5. Прерывание и бюджет

- Любой переход прерывается новым действием без «отката»: CSS-переход стартует с текущего интерполированного значения.
- Наведение не запускает цепочки: hover — один FAST-переход, никаких каскадов от одного события.
- Кадровый бюджет: активных анимаций ≤ 3 одновременно; каждая < 2ms/frame на среднем железе (Tauri/WebView).
- Поиск (debounce 300ms) и сохранение (debounce 800ms из §6 спеки) — тайминги логики, не анимации; визуально — только бейджи FAST.

## 6. `prefers-reduced-motion: reduce`

Все переходы → ≤ 1ms (спека §1.4). Смысл не теряется, потому что цвет/глиф/текст несут состояние, а не движение.

| Осталось | Упрощено |
|---|---|
| Мгновенная смена цветов, глифов, счётчиков (это не движение, а состояние) | Все transform-пути: view transition, панели, toast, модалка → fade 1ms или мгновенно |
| Каркас skeleton-строк (место резервируется, layout не прыгает) | Shimmer и indeterminate-loop → статичная заглушка / полоса с текстовым % |
| Focus ring, hover-подложки (мгновенные) | Stagger → отключён полностью |
| Scroll — штатный, `scroll-behavior: auto` | Появление/скрытие dropdown, inline edit → мгновенные |
| Прогресс: текстовые фазы и проценты | Полоса прогресса без scaleX-перехода (шагами) |

## 7. Запреты

1. **No per-row table animation**: никакой анимации появления/удаления/перекраски строк — виртуализация + десятки тысяч строк делают её и дорогой, и бессмысленной.
2. **No gratuitous motion**: нет пульсирующих логотипов, параллакса, «дышащих» градиентов, декоративных петель.
3. Никакого stagger по спискам > 8 элементов и никакого stagger в Workspace.
4. Не анимировать font-size, line-height, letter-spacing (reflow и дёрганый текст).
5. Не анимировать геометрию таблицы: высота строки 40px и сетка колонок инвариантны во всех состояниях.
6. Движение не может быть единственным носителем смысла (WCAG 2.1 / 1.4.1, 2.3.3): статус, ошибка, прогресс читаются при отключённых анимациях.
7. Не блокировать ввод анимацией:Esc/клик по фону модалки срабатывают немедленно, exit-анимация — фоновая.
8. Никаких звуковых эффектов и вибро-имитаций (desktop-инструмент).

## 8. Реализация в Svelte 5

- Переходы — CSS `transition` в компонентах; `svelte/transition` (fade/fly/scale) — только для modal/dropdown/toast, где монтирование/размонтирование неизбежно.
- Ключевые константы — токены `--dur-fast|standard|emphasis`, `--ease-out-quad|decel|accel|accel-exit`, `--motion-shift-1: 4px / -2: 8px / -3: 16px` (см. `GUI_DESIGN_TOKENS.md`); сырые значения в компонентах запрещены.
- Списки: `animate:flip` в таблице запрещён; допустим только в списке «Недавние проекты» на Home.
- Тест-план: скриншотные E2E запускаются с `prefers-reduced-motion: reduce` — детерминизм кадров.
