# Competitor Matrix — код-левел сравнение с RimLoc

Цель документа — зафиксировать, **как** конкуренты реализуют функции перевода модов RimWorld (по исходникам, не по README), сопоставить с текущей поддержкой в RimLoc и получить список приоритетных гэпов для имплементации.

## Методология

- **Дата**: 2026-09-23.
- **RimLoc**: прочитаны `crates/rimloc-parsers-xml/src/lib.rs`, `crates/rimloc-services/src/` (scan, build, export, import, keyed_merge, validate, learn/*, extras/*), `crates/rimloc-validate/src/lib.rs`, `crates/rimloc-import-po/src/lib.rs`, `crates/rimloc-export-po/src/lib.rs`, `crates/rimloc-cli/src/main.rs`. Колонка «RimLoc» — по коду, не по документации.
- **Клоны конкурентов** (`~/Developing/_competitors-rimloc/`), прочитаны исходники:
  - **Text-grabber** (Python/Tkinter, ~7.8k строк, автор kamikadza13). **Лицензии в репо нет** — поведение описано для анализа, код не копируется и не переносится.
  - **RimLangKit** (C# WinForms, .NET 9, **Apache-2.0**, OneCodeUnit/Vanilla Russian Expanded).
  - **RimTrans** (monorepo: extractor на TypeScript, Reflection на C#, GUI Electron+Vue WIP, **MIT**, RimWorld-zh).
  - **RimTranslate** (Python CLI, один файл 372 строки, **GPL-3.0**, winterheart).
  - **RimWorldAiTranslator** (C# WinForms, Core/App слои, **MIT**, © 2026 wjdck; Korean-focused).
  - **rimworld-autonomous-translator** (AutonomoAI): **кода в репо нет** — один коммит «Initial», только README/INVESTORS (проверено `git branch -a` и `gh api repos/...`: `license: null`). Всё, что о нём известно — описание конвейера из README (непроверяемо).
- Функциональные термины — английские, проза — русская.
- Статусы: `gap` (в RimLoc нет), `partial` (есть, но слабее/в другом виде), `parity` (сопоставимо), `better` (RimLoc сильнее).
