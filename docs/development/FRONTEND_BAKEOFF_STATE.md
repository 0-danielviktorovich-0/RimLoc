# FRONTEND STACK BAKE-OFF — §1 текущее состояние (Svelte 5)

Мандат 05 (NO migration yet). §1 — аудит миграционной поверхности текущего Svelte-фронта,
измерено 30.09 на main `033e169`. §2-§3 (кандидаты/React-POC) — отдельные шаги, требуют
воркер-слота; выводы этого документа — их вход.

## Измерения

| Метрика | Значение |
|---|---|
| Svelte-компоненты | 48 файлов, ~20 400 LOC |
| TS (без generated) | 53 файла, ~12 835 LOC |
| Тесты (vitest) | 42 файла, ~8 435 LOC (433 теста) |
| T2a e2e | 4 спеки + helpers, ~616 LOC (+генератор T5-сцен) |
| Прод-зависимости | **0** (runtime-нуль) |
| devDeps | svelte 5, vite 7, vitest 5, @playwright/test 1.63, svelte-check, tsx |

## Svelte-специфика (что придётся переносить при миграции)

- **Руны**: 55 файлов с `$state` (+ `$derived`/`$props` в компонентах) — основная
  миграционная масса. Идиома «store-класс с полями-ранами» (src/lib/stores/*.svelte.ts,
  15+ сторов) — прямого React-аналога нет (useState-набор/контекст/zustand — редизайн).
- **svelte-ignore/a11y-директивы** в разметке — точечные, машинно-находимы.
- **Ноль** использования legacy `svelte/store` — код уже на рунах 5.x (нет двойной
  стоимости перехода).

## Tauri-связанность и mock/live разделение (migration-safe ядро)

- Прямые `invoke`/`@tauri-apps` — **3 файла** (transport-слой); остальные ~73 файла
  работают через `clientInstance`/`RimLocClient`-контракт (20 файлов ссылок).
- `src/lib/client/` — чистый шов: types/transport/client/mock/instance/capability/messages.
  **Переносимая оценка:** UI-слой не знает Tauri; подмена транспорта — точка инъекции
  (уже используется vitest-фейками и Playwright browser-режимом).
- i18n: TS-словари — единственный авторитет + generated-мост (SELFLOC_BRIDGE) — вне
  фреймворка.

## Тест-корпус как страховка миграции

433 vitest (jsdom-mount компонентов — Svelte-специфичны, при миграции переписываются на
целевой рендер), 16+1 e2e **семантических** (ARIA/testid — фреймворк-агностичны, переносятся
бесплатно), 36 T5-сцен (пиксельная база сравнения «до/после» любой миграции).

## Предварительный вывод для §2/§3

Runtime-нуль зависимостей + чистый транспорт-шов + семантические e2e — миграционная
поверхность **уже минимизирована архитектурно**; основной вес — руны-сторы (55 файлов) и
jsdom-тесты. POC обязан доказать измеримую выгу React именно по workstation-критериям
(таблицы 10-15k, a11y-компоненты, AI-разработка), иначе по мандату 05 §25 остаёмся на
Svelte. Порог сравнения зафиксирован этим документом.
