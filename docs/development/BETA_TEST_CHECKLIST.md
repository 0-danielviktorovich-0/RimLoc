# BETA TEST CHECKLIST — RimLoc RC

Чек-лист для бета-тестера. Порядок — снизу вверх по риску: сначала установка, потом базовый цикл, потом краевые случаи. Время полного прохода — 30–45 минут. Если пункт не проходит — зафиксируй, что делал, и собери отчёт (последний раздел).

## 0. Подготовка

- [ ] ОС: macOS 14+ (проверено на macOS 27, Apple Silicon). Windows/Linux — сборка из исходников, верификация приветствуется.
- [ ] RimWorld-мод для теста: обычный мод с `Languages/English/Keyed` и/или `Defs` (подойдёт любой из Workshop, он читается read-only и не модифицируется).
- [ ] Сборка: по README (`cargo build` CLI + GUI через npm/tauri), либо готовый билд от владельца.

## 1. Первый запуск и проект

- [ ] Приложение открывается, экран Home живой, курсорные подсказки на месте.
- [ ] «Новый проект»: указать корень мода → скан находит записи (попробуй мод от 500 до нескольких тысяч записей; на 15k скан ~1.5 с).
- [ ] После создания проект появился в «Недавних»; перезапусти приложение — проект открывается из списка, записи на месте.

## 2. Перевод и сохранение

- [ ] Открыть любую запись, ввести перевод, поле становится «грязным» (черновик сохраняется при рестарте приложения — закрой и открой, черновик на месте).
- [ ] Сохранить (применить) — статус/счётчики обновились. На моде в тысячи записей заметь задержку сохранения: до ~0.1–0.3 s нормально; заметные секунды на 10k+ — известное ограничение (K1), фиксируй ощущения.
- [ ] Попробуй два проекта одновременно (два окна-таба): переключение не путает содержимое.

## 3. Проверка проекта (валидация)

- [ ] «Проверить проект» на корректном переводе — «Ошибок нет».
- [ ] Сломай специально один перевод (убери `{0}`-плейсхолдер или напиши `{0]`) → проверка находит проблему, статус «Есть ошибки», находка кликабельна к записи.
- [ ] Дубликат ключа в исходнике (если умеешь сделать) → дубликат виден в находках.

## 4. Экспорт и сборка

- [ ] Экспорт: укажи **абсолютный** путь папки (например `/Users/<ты>/Documents/RimLoc-Export`). Успех: «Записано и перепроверено», файлы существуют.
- [ ] Попробуй ввести относительный путь (например `RimLoc-Export`) → приложение обязано **отказать** с сообщением про абсолютный путь (это новый гард, не баг).
- [ ] Build: собери мод-пакет из перевода в отдельную папку, убедись что в папке появился корректный `Languages/<язык>/…` и мод грузится в RimWorld (если проверяешь в игре).

## 5. Диагностика и отчёт

- [ ] «Полная диагностика» → «Собрать бандл»: создаётся папка с `report.md`, `diagnostics.json`, `manifest.json`. В `report.md` — цепочка причин по последней ошибке валидации, секретов нет.
- [ ] Справка → «Подготовить отчёт»: превью содержимого (таблица Included), пароль/токены/пути пользователя не включаются.

## 6. Краевые случаи (желательно)

- [ ] Измени файл проекта на диске вручную (или второй копией приложения), затем нажми «Сохранить» в приложении → должен появиться баннер «файл изменён извне» с кнопкой **«Принять версию на диске»**; нажатие перезагружает проект, приложение остаётся рабочим.
- [ ] Вызови любую ошибку (несуществующий путь, битый файл) → ошибка показывается **текстом в интерфейсе**, а не молчаливым «ничего не произошло».
- [ ] Открой папку мода в проводнике и меняй там `Languages/` во время открытого проекта → при следующей валидации/действии приложение сообщает о дрейфе источника (source-drift), а не молчит.

## 7. Известные ограничения (не баги)

- Сохранение на очень больших модах (10k+) занимает до ~1 с (K1).
- Версия приложения пока `0.1.0-alpha.1` (K2).
- Relative-пути на экспорт отказываются намеренно (новый гард).

## 8. Если что-то сломалось

1. Справка → «Полная диагностика» → «Собрать бандл» — сохрани папку.
2. Справка → «Подготовить отчёт» — превью, затем сохрани.
3. Приложи к обращению: что делал (пункты этого чек-листа), ОС, шаг воспроизведения, бандл. Лог приложения: `<данные приложения>/RimLoc/logs/gui.log`.
