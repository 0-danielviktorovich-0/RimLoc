## Результаты слепого извлечения

Сырые данные: `testlab/benchmarks/extraction-*.json|.md` · протокол: `testlab/scripts/blind_benchmark.py`.

### Мод со своим EN+RU (VWE)

- RimLoc (1.6): 317 EN-ключей; референс RU: 397; пересечение 144.
- **Adjudication всех 253 «reference-extra»** (руко-классифицировано по корневым причинам):
  1. **VEF-derived recipes** (`Make_*.label/jobString`) — рецепты генерируются Vanilla Expanded Framework в рантайме из `recipeMaker`-компов; в XML мода их нет. RimLoc не может «извлечь» несуществующий текст → фича-идея: derived-entries (генерация конвенциональных рецептов из label вещи). P2, VE-конвенция.
  2. **Version-skew** — пак переводит контент 1.4/1.5 (напр. `Dam_OPToxin` из `Damages_Gases.xml`, отсутствующего в 1.6). RimLoc корректно извлекает по версиям (`--include-all-versions`); union-скан подтверждает: 1.5 ⊂ union.
  3. **Speculative translations** — `Dam_OPToxin.deathMessage` переводится при отсутствии поля в исходном XML (1.5 проверен grep) — эталон здесь шире реальности.
  4. **Форматные варианты** (`tools.li{h}.label`) — конвенция именования референса, не извлечение.
- Вывод: **extracted-миссов класса «реальная строка в XML, которую RimLoc не увидел» — не обнаружено** на VWE.

### Пак↔база (Genetics)

- База EN (RimLoc): **2340** ключей; пак RU: 3425 (мега-пак, покрывает и другие моды); пересечение **1936 = 82.7% базы**.
- 404 базовых ключа не переведены паком (в осн. `ThoughtDef.stages.li.*`) — **неполнота AI-перевода, не дефект RimLoc**.
- 1489 пак-ключей вне базы —Translation-пак покрывает дополнительные моды; для точной метрики нужен разбор по родительским модам (todo итерации 3).

## Найденные и исправленные дефекты кампании (из бенчмарка)

1. **P1 version-resolver**: падение на плоских модах с supportedVersions — исправлено (fallback на корень), коммит до бенчмарка.
2. **P2 feature**: derived-entries для VEF-рецептов — зафиксировано в COMPETITOR_MATRIX (Text-grabber решает похожее dependency-aware генерированием).
3. **Наблюдение**: `--include-all-versions` корректно объединяет Languages, Defs-часть требует проверки на мульти-версионных модах с расходящимися дефами (тут версии почти идентичны).
