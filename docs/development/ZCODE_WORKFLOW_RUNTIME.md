# ZCode Workflow Runtime — factual contract (проверено 6 запусками вала 1-5 + волна 5-аменд)

Практический контракт встроенного Workflow-инструмента ZCode (dynamic workflows),
проверенный на кампании RimLoc 05-06.10.2026. Только то, что нужно для воспроизводимой
оркестрации; internal implementation не документируется.

## Создание и жизненный цикл
- `CreateWorkflow` принимает **script** (TypeScript, инлайн → сохраняется в `.zcode/workflow-drafts/*.dwf.ts`) или **path** к файлу. Компиляция строгая; diagnostics = ничего не запущено.
- Запуск **фоновый**: run продолжается независимо от ходов сессии и ПЕРЕЖИВАЕТ новые сообщения владельца (проверено: волны 2/4/5 пережили 3 прерывания мандатами). Обычные Agent-вызовы гаснут при прерывании — длинные лейны только через Workflow.
- Результат приходит уведомлением при завершении; артефакты (board/markdown) видны владельцу в UI во время и после.
- `AmendWorkflow` на **running** run: останавливает, импортирует завершённое как кэш, запускает ревизию. Дешевле, чем ждать зависший лейн (проверено: перф-лейн висел 3ч11м → amend → рестарт за секунды).
- Ошибки = stop с причиной (provider quota/sign-in и т.п.) → `ResumeWorkflowRun`/`AmendWorkflow`.

## Script API (фасад)
- `agent(name, {system}) → ask<T>(brief): Node<T>` — именованный актор, кэш по имени+тексту ask; уникальность имён обязательна; персоны стекаются к harness-контракту.
- `phase("...")` — человекочитаемые стадии (обязательны, ≥1 ask/world.run на фазу).
- `world.run(cmd, args, {timeoutMs})` — детерминированный гейт; cmd — строковый литерал (апрув команд владельцем при подтверждении); nonzero exit = значение, не исключение.
- `report(item, artifactId?)` + `artifact.board/markdown/file` — прогресс и деливераблы (id — литералы).
- `Promise.all` — fan-out; чекауты/барьеры только где данные нужны всем.
- Запрещено: import, Node API, Date.now, fetch, fs (файловые операции — через агентов).

## Проверенная практика
- Структура результата: `interface LaneResult { lane, status, summary, artifacts, blockers }` + board + финальный markdown.
- Worktree/изоляция: Workflow-скрипт НЕ изолирует файловую систему сам — изоляция через брифы агентов (отдельный worktree/ветка на лейн, дисциплина one-writer-per-hotspot).
- Таймбоксы в брифах обязательны для WDIO/сборочных лейнов (прецедент: перф-лейн без таймбокса завис 3ч11м; amend + таймбокс = 35 мин до результата).
- Эскалация агента (dwfq-вопрос) приходит уведомлением; ответ через `ResolveWorkflowQuestion` возобновляет только этого агента.
